# Appendix: 54 Complex Numbers Problem Types

This directory contains the appendix for the paper submitted to SoICT 2026.
It lists the 54 Complex Numbers problem types, coded D01 through D54, used in
the study. The result tables in the paper show only these codes.

- The complete English list is available in the
  [repository README](../README.md#appendix-54-problem-types-complex-numbers).
- The machine-readable bilingual list is available in
  [`problem_types_54.csv`](problem_types_54.csv).
